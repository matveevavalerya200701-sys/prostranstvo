# Пространство: как запустить своё приложение

Приложение не зависит от Claude. Это обычный сайт, который можно установить на телефон и компьютер как приложение. Без интернета он тоже работает: изменения сохранятся на устройстве и отправятся позже.

Всё бесплатно. Понадобится примерно 15 минут, и делается это один раз.

## Шаг 1. Выложить приложение в интернет (GitHub Pages)

1. Зарегистрируйтесь на [github.com](https://github.com/signup).
2. Нажмите «+» вверху справа → **New repository**.
   - Repository name: `prostranstvo`
   - Выберите **Public**: бесплатные сайты работают только с публичными репозиториями. Ваши данные туда не попадают, там лежит только код приложения.
   - Нажмите **Create repository**.
3. На странице репозитория нажмите ссылку **uploading an existing file**.
4. Перетащите туда все файлы из папки приложения, включая папку `vendor`, и нажмите **Commit changes**.
5. Откройте **Settings** → **Pages**. В разделе Branch выберите `main` и папку `/ (root)`, затем нажмите **Save**.
6. Через 1–2 минуты приложение откроется по адресу `https://ВАШ-ЛОГИН.github.io/prostranstvo/`.

Можно сделать проще: подключите GitHub к Claude по ссылке [claude.ai/connect-github](https://claude.ai/connect-github), создайте пустой репозиторий (пункты 1–2) и напишите мне его название. Файлы я загружу сама, и дальше смогу сама выкладывать обновления.

## Шаг 2. Включить синхронизацию между устройствами (Supabase)

1. Зарегистрируйтесь на [supabase.com](https://supabase.com). Удобнее всего войти через GitHub.
2. Нажмите **New project**. Укажите любое имя, придумайте пароль базы (его можно не запоминать) и выберите регион **Frankfurt** или другой европейский. Подождите около минуты.
3. Слева откройте **SQL Editor**, вставьте целиком содержимое файла `supabase.sql` и нажмите **Run**. Должно появиться «Success».
4. Слева откройте **Authentication** → **Sign In / Providers** (или **Providers**) → **Email** и выключите **Confirm email**. Так не придётся подтверждать почту письмом.
5. Откройте **Project Settings** → **API** (или **Data API** и **API Keys**) и скопируйте две вещи:
   - **Project URL** вида `https://xxxx.supabase.co`;
   - публичный ключ **anon public** (или **publishable**).
6. Откройте приложение, нажмите надпись внизу слева «Только на этом устройстве», вставьте адрес и ключ и нажмите **Подключить**. Затем нажмите **Создать аккаунт**, введя почту и пароль.
7. На других устройствах откройте тот же адрес, тоже вставьте адрес и ключ, а затем нажмите **Войти** с теми же почтой и паролем.

Чтобы не вводить адрес и ключ на каждом устройстве, впишите их один раз в файл `config.js` (или пришлите мне, я впишу сама). Ключ публичный, это безопасно: без вашего пароля данные никто не увидит.

## Шаг 3. Установить как приложение

- **iPhone:** откройте адрес в Safari → «Поделиться» → «На экран „Домой“».
- **Android:** откройте адрес в Chrome → меню ⋮ → «Установить приложение».
- **Компьютер:** в Chrome или Edge нажмите значок установки справа в адресной строке.

## Перенести данные из версии в Claude

1. В версии в Claude нажмите внизу слева значок со стрелкой вниз («Скачать резервную копию»).
2. В новом приложении нажмите значок со стрелкой вверх («Загрузить из файла») и выберите скачанный файл.

## Резервные копии

Кнопка со стрелкой вниз внизу слева в любой момент скачивает все данные в один файл. Время от времени это полезно делать.
